Episodio

Simulación determinista a paso fijo. Cada acción avanza 0,5 s de juego. El modelo solo ve la imagen de 768×480; el estado interno queda para puntuar.

Acciones

Teclado: W A S D, E comer, F morder, R cantar, 1–3 evolucionar. Una pulsación, un paso.

Salida

API para el harness

SporeBench.reset({seed:7, maxSteps:600})
SporeBench.actions   // lista de acciones
r = SporeBench.step('forward')
// {reward, dna, done, outcome, step}
png = SporeBench.observe() // data URL
SporeBench.state()   // verdad terreno

Puntuación: ADN al terminar (0–100). El episodio acaba al llegar a 100, al morir o al agotar los pasos.
