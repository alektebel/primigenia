# Food Plants & Ground Cover (G66)

## How to view

Open `web/props/food.html` in any browser. It loads Three.js r128 from CDN and renders all food plants and meadow ground cover on a patch of meadow ground.

Controls:
- **Mouse drag**: orbit camera
- **Scroll**: zoom
- **Full / Depleted**: toggle berry bush depletion state
- **Random Seed**: generate new seed (deterministic)
- **Capture Grid**: screenshot 6 camera angles

## What is included

### Food plants (P4 herbivore food store)
| Plant | Description | States |
|-------|-------------|--------|
| Berry Bush | Round shrub, trunk + branches + leaf clusters + berry spheres | Full / Depleted (eaten) |
| Tuber Leaves | Broad low-lying leaf cluster with midrib + grass tufts | Full (tuber underground) |
| Fruiting Stalk | Tall thin stalk with leaf blades + fruit cluster at top | Full |

### Meadow ground cover (G12 — G66: "generated by agents, procedural in JS")
| Type | Description | Format |
|------|-------------|--------|
| Flower Patches | 4 color variants: pink, blue, orange, purple | InstancedMesh |
| Moss Patches | Low irregular ground patches | InstancedMesh |
| Fern Patches | Frond shapes with leaflets | InstancedMesh |
| Clover Patches | 3-leaf clusters | InstancedMesh |

## How it works

- Each builder function takes `(THREE, seed, params)` and returns a `THREE.Group` or `InstancedMesh`
- Geometry is deterministic from seed: `rng(seed ^ 0xXXXX)` uses the same hash function as `growth.js` and `studio.js`
- Materials use `MeshStandardMaterial` with appropriate colors and roughness matching the valley's palette C
- The food.js file can be imported as an ES module; the food.html includes an inline copy for standalone preview

## Known issues

- Shadows not visible in SwiftShader software WebGL (rendered correctly in real GPU browsers)
- food.js module needs `position.set()` instead of object spread for Three.js r128 compatibility
- No toon gradient map rendering in software mode — uses MeshStandardMaterial instead
