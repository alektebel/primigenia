The owner decided to move the game to Godot 4, desktop only, keeping all prior work (docs/DESIGN.md G76; read also G57, G63, G70–G75, W11–W20, docs/BACKLOG.md section 0). Godot 4.7.2 is installed: `godot` (~/.local/bin/godot → ~/.local/opt/godot). You may download godot-cpp (matching 4.7) and SCons via pip into a venv under /home/diego/Desarrollo/cpore-wt/_agent/ (not into the repo, not system-wide); no other installs.
Build the foundation in a new top-level folder godot/ (project.godot, scenes, scripts in GDScript; native code in godot/extension/):
1. GDExtension "cpore" (godot-cpp, C++ glue only; the simulation stays in core/ C99, linked as libcpore.a, determinism flags unchanged): expose the terrain generator (core/include/cpore/terrain.h: params, generate with progress, maps height/flow/sediment/material, caves), the stage world (world.h: create/reset, step with inputs, state, observation), and combat as needed by the world. Build with scons from the Makefile (`make godot`).
2. Island: generate from a seed with the W20 defaults; cache the generated maps on disk in user:// keyed by seed + generator version (W13 + G76: generated once, then instant); a loading screen with progress the first time. Terrain mesh in chunks with LOD (far mountains visible), material shading from the material map (meadow, rock, scree, volcanic, sand, snow) in the stylised look of the approved hero (palette C "Current+": see tools/hero/build_hero.py PAL.C and the toon ramp), sea with shoreline, sky with sun, distance fog/aerial perspective, and world-anchored grass (MultiMesh around the camera, wind) like the approved grass.
3. Your creature from a cpore.creature/4 genome (web/studio genome format; port the spine sweep body and the leg IK from web/creature/rig.js; other parts may be simple placeholders in M0 and are listed as TODO for M1).
4. Spore-style chase camera (G72 numbers: pitch 12–18° below horizontal, look-at ~1.5× creature height above it, horizon in the upper third, distance 5–7× height, auto-follow ~0.4 s, free orbit with right/middle drag, wheel zoom with pitch rising as it zooms out, terrain collision) and controls: click/hold to walk toward the pointer, WASD camera-relative, driving the C world (positions come from C at 10 Hz with interpolation).
5. Tests: headless GDScript tests (`godot --headless --script ...`) for the extension (terrain hash equals build/terrain_cli for a seed; world steps deterministically; cache hit on second load), wired into `make godot-test`. Keep `make test` and the core tests green; do not modify core/ algorithms.
6. Evidence: screenshots of the island from the chase camera, a far view and the creature close. Rendering needs a display: use xvfb-run if available with software GL (LIBGL_ALWAYS_SOFTWARE=1, --rendering-driver opengl3); if no headless display is available, do not open windows on the user's desktop — skip screenshots and say so. Write godot/README.md (how to build and run: `make godot && godot --path godot`).
Commit as you go.
